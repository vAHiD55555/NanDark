# 2535 — Idea Vault

This directory holds all ideas: raw and mature.

## Structure

| Path | Purpose |
|---|---|
| `01-initial/` | Raw, unstructured, early-stage ideas |
| `02-mature/` | Refined, actionable, execution-ready ideas |
| `README.md` | This file |

## Naming convention
- `YYYY-MM-DD_short-title.md`
- Example: `2026-10-10_blackbird-observer.md`

## Entry template
```markdown
# Title

- **Status**: Initial | Mature
- **Date**: YYYY-MM-DD
- **Domain**: Trading / AI / Commerce / Infrastructure / Other

## Problem

## Hypothesis

## Evidence

## Risks

## Next step

## Decision / Outcome
```

## Rules
- Raw ideas stay in `01-initial/` until validated.
- Move to `02-mature/` only when there is evidence and a clear next step.
- Never delete; archive with a date stamp instead.
