# Contributing to NanDark

Thank you for your interest in contributing to NanDark! This document outlines the guidelines for contributing to the project.

## Getting Started

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/amazing-feature`)
3. Make your changes
4. Run tests (if applicable)
5. Commit your changes (`git commit -m 'Add some amazing feature'`)
6. Push to the branch (`git push origin feature/amazing-feature`)
7. Open a Pull Request

## Coding Standards

- Write clean, readable code
- Add comments for complex logic
- Follow the existing code style
- Write tests for new features
- Ensure all tests pass before submitting

## Commit Guidelines

- Use clear, descriptive commit messages
- Reference issues in commit messages when applicable
- Break large changes into multiple commits if necessary

## Pull Request Process

- Describe what your PR does
- Explain why it's needed
- Note any known limitations
- Link to related issues

## Reporting Issues

- Use the issue template
- Provide steps to reproduce
- Include expected and actual behavior
- Add relevant logs or screenshots

## Questions?

Open a Discussion for questions or architecture questions.

Thank you for contributing!
